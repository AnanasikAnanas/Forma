# FORMA

Демонстрационный сайт-портфолио независимого digital-ателье для локального бизнеса: студий красоты, барбершопов, клиник, ресторанов, экспертов и сервисных компаний.

Все проекты, названия, контакты и описания результатов на сайте являются демонстрационными.

## Стек

- Next.js 16 с App Router и TypeScript
- Tailwind CSS 4
- Framer Motion для коротких reveal-анимаций
- React Hook Form и Zod
- lucide-react
- next/image и next/font
- ESLint, Prettier, Node Test Runner
- vinext/Vite для совместимого Cloudflare Sites build

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который появится в терминале (обычно `http://localhost:3000`).

## Проверки и production-сборка

```bash
npm run typecheck
npm run lint
npm test
npm run format:check
npm run build
```

## Переменные окружения

Скопируйте `.env.example` в `.env.local` и заполните нужные значения:

```env
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

Telegram-токен используется только в серверном API и никогда не попадает в клиентский bundle. Если Telegram-переменные не заданы, форма всё равно валидируется; в development заявка выводится в серверную консоль.

## Структура

```text
src/
  app/          страницы, metadata, sitemap, robots и API
  components/   общие, домашние, проектные, сервисные и form-компоненты
  config/       настройки сайта
  data/         проекты, ниши, услуги и контент
  lib/          схема формы и калькулятор стоимости
  types/        общие TypeScript-типы
public/
  images/work/  локальные демонстрационные mockup-изображения
tests/          unit-тесты калькулятора
```

## Добавление проекта

1. Добавьте объект в `src/data/projects.ts`.
2. Положите `hero.png`, `screen-01.png` и `screen-02.png` в `public/images/work/<slug>/`.
3. Укажите тот же `slug` и пути в объекте проекта.

Страница `/work/<slug>` и переход к следующему кейсу появятся автоматически.

## Добавление ниши

Добавьте объект типа `BusinessType` в `src/data/business-types.ts`. Интерактивный выбор на главной сформируется из этого массива автоматически.

## Изменение услуг и цен

- базовые услуги: `src/data/services.ts`;
- цены интерактивного калькулятора: `src/lib/cost-calculator.ts`;
- бюджетные диапазоны формы: `src/components/forms/ContactForm.tsx`.

После изменения логики калькулятора обновите тесты в `tests/cost-calculator.test.mjs`.

## Замена изображений

Заменяйте PNG в `public/images/work/<slug>/`, сохраняя имена файлов, либо обновите пути в `src/data/projects.ts`. Рекомендуемое соотношение — 14:9, ширина от 1400 px. Используйте изображения без водяных знаков и указывайте содержательный `alt` при добавлении новых вариантов.

Скрипт `scripts/generate-placeholders.mjs` пересоздаёт текущие демонстрационные mockup-заглушки. После подключения реальных материалов его можно удалить.

## Подключение Telegram

1. Создайте бота через BotFather.
2. Получите ID чата, куда должны приходить заявки.
3. Укажите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в окружении хостинга.
4. Отправьте тестовую заявку.

API находится в `src/app/api/contact/route.ts`. Там реализованы серверная Zod-валидация, honeypot, ограничение длины, нормализация контакта и базовый rate limit. Заявки не сохраняются в базе данных.

## Деплой на Vercel

1. Импортируйте репозиторий в Vercel.
2. Добавьте переменные окружения.
3. Используйте стандартные команды установки и сборки из `package.json`.
4. Укажите публичный адрес в `NEXT_PUBLIC_SITE_URL` и выполните новый deploy.

## Деплой на другой Node.js-хостинг

Хостинг должен поддерживать Node.js 22+, установку npm-зависимостей и постоянный процесс. Выполните `npm install`, `npm run build`, затем `npm run start`. Переменные окружения задайте в панели хостинга или в безопасном секрет-хранилище.

## Отключение демонстрационных данных

1. Замените массивы в `src/data/` реальным согласованным контентом.
2. Замените изображения в `public/images/work/`.
3. Удалите подписи о демонстрационном характере только после проверки прав на публикацию названий, отзывов и результатов.
4. Обновите контакты в `src/config/site.ts`, metadata и schema.org в `src/app/layout.tsx`.
5. Не добавляйте неподтверждённые числовые результаты, рейтинги или отзывы.
